# بوت يوهان الجزائري لتيليجرام

بوت تيليجرام مرح باسم **يوهان**، يرد على كل رسالة نصية في المجموعات بردود جزائرية متنوعة. يرد تلقائيًا على عبارات مثل «سلام عليكم» و«صحا»، ويستخدم ردودًا عامة مرحة لباقي الرسائل.

## المزايا

يعالج البوت كل رسالة نصية في المجموعة، ويتجاهل رسائل البوتات والرسائل غير النصية حتى لا يدخل في حلقة ردود. توجد أوامر `/start` و`/help` و`/stats`، ويمكن تعديل الردود من أعلى ملف `bot.py` داخل القائمتين `GENERAL_REPLIES` و`KEYWORD_REPLIES`.

## إعداد التوكن

انسخ `.env.example` إلى ملف اسمه `.env`، ثم ضع توكن البوت في السطر التالي:

```env
TELEGRAM_BOT_TOKEN=ضع_توكن_البوت_هنا
BOT_NAME=يوهان
```

لا ترفع ملف `.env` الحقيقي إلى GitHub ولا ترسل التوكن في المحادثات. ملف `.gitignore` يمنع رفعه بالخطأ.

## التشغيل محليًا

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

أضف البوت إلى المجموعة، ثم عطّل **Privacy Mode** من BotFather إذا أردته أن يرى كل الرسائل وليس فقط الرسائل التي تبدأ بمنشن أو أمر. يحتاج البوت إلى صلاحية قراءة الرسائل في المجموعة بحسب إعدادات تيليجرام.

## النشر على Render

أنشئ Worker جديدًا من هذا المستودع، أو استخدم ملف `render.yaml`. اجعل أمر البناء:

```text
pip install -r requirements.txt
```

واجعل أمر التشغيل:

```text
python bot.py
```

في قسم Environment Variables أضف المتغير `TELEGRAM_BOT_TOKEN` وضع التوكن كقيمة سرية، ثم أعد التشغيل. لا تستخدم Web Service لهذا النوع من البوتات؛ العامل Worker مناسب لعملية polling المستمرة.

## ملاحظة أمنية

إذا تم نشر التوكن أو مشاركته مع أي شخص، ألغِه فورًا من BotFather باستخدام `/revoke` وأنشئ توكنًا جديدًا، ثم حدّث قيمة `TELEGRAM_BOT_TOKEN` في Render.
